# AI Fluency Training Task

## Overview

This repository contains the work completed as part of the AI Fluency Training Task.

The task focuses on understanding and applying fundamental concepts related to Generative AI, Large Language Models, prompting, AI agents, tool calling, workflows, and responsible use of AI.

## Objectives

* Understand the fundamentals of Artificial Intelligence and Generative AI.
* Learn how Large Language Models (LLMs) work at a basic level.
* Understand prompts and effective prompt design.
* Explore AI agents and their ability to use tools.
* Understand workflows and step-by-step task execution.
* Learn about responsible and safe use of AI.

## Topics Covered

* Artificial Intelligence
* Generative AI
* Large Language Models (LLMs)
* Prompt Engineering
* AI Agents
* Tool Calling
* Workflows
* Retrieval-Augmented Generation (RAG)
* Hallucination and Grounding
* AI Safety and Responsible AI
* APIs and API Keys
* Git and GitHub

## Project Structure

The repository contains the files and resources completed during the AI Fluency Training Task.

## Key Learning

The training helped in understanding how AI systems can process user prompts, generate responses, use external tools when required, and follow structured workflows to solve problems.

A key concept understood during the task was:

**Prompt → LLM → Agent → Tool → Result → Final Answer**

1. Clone the repository.
